# Field experiments and evidence protocol

No field tests have been run. Do not place synthetic data in a measured-results folder or publish a successful calculator as field proof.

## Cheapest falsifier: rent height before inventing it

Budget estimate $1,500–$3,000 plus paid field days. Rent/borrow a certified adjustable mast; survey twenty candidate homes at multiple heights; measure both directions; get binding carrier/site quotations; compare fixed and adaptive geometry plans.

Reject this market if height/relocation adds little qualified demand, customer-side foliage dominates, existing roofs already do the job cheaply, upstream costs defeat the model, or mechanism maintenance exceeds avoided work. This rejects the proposed advantage in that market, not every satellite-free idea.

## Gates

| Test | Pass criterion | Failure response |
| --- | --- | --- |
| Geometry benefit | >=30% more qualified homes than fixed low-mast plan without more permanent sites | Use ordinary WISP/fiber or another site |
| Access | Legal 5 km qualified path sustains 100/20 at low load with logged fade margin | Shorten path, improve topology, revise service |
| Busy hour | 20 profiles/sector averaging 4/.8; >=95% random probes exceed 25/5 under stated scheduling | Add capacity or reduce admission |
| Reuse | Full multi-site throughput >=80% of isolated sum | Replan channels/sites or licensed spectrum |
| Backbone | Required hub fallback >=300/75 net at admitted loads | Reprice and add capacity |
| Physical handover | Protected users interrupted <=5 s while cartridge lowered / height altered | Revise dual access and sequencing |
| Maintenance | Ground exchange <=15 min excluding travel; >=50% lower paid time versus control | Mechanism advantage fails |
| Energy | Hub average <=75 W representative load; 12-hour battery trial ends with reserve | Reprice power/storage |
| Structure | Independent engineer-defined load, lock-loss, power-loss and staged deployment tests pass | No public installation |
| Optics | >=1 Gbps at stated distance and margin; automatic RF transfer during obscuration | Retain RF/fiber, do not sell optical peak |
| Availability | Seasonal logs support outage budget; annual claim needs suitable duration/evidence | No unsupported SLA |
| Cost | Actual quotes/labor support budget and mature <=895/home with equivalent service | Quarter-cost claim fails |

## Measurements

Record UTC timestamps, test ID, classification, instruments/calibration, firmware/configuration hash, distance and surveyed profiles, legal radio settings, weather, concurrent traffic, useful payload throughput, retries/loss, RTT p50/p95/p99, power, actual labor and all outage causes. Preserve original observations and a separate transformation script. Report failed runs, not just best cases.

Collect upstream and endpoint performance separately. Test both carriers down, common-duct failures, optical fog, RF degradation, CPE power loss, stale telemetry and cartridge jams. No deliberate harmful RF interference or unsafe structural stress in occupied/public areas.

Run purchased Starlink at selected consenting homes concurrently to the same destinations and workload. Match installation quality, service plan, taxes, availability definition and reporting periods. Do not use a higher Starlink plan just to improve the cost ratio.

## Data privacy

Public evidence uses pseudonymous site IDs and generalized locations. Do not publish home addresses, identifying logs, ISP secrets, customer traffic contents or critical-infrastructure coordinates. Keep consent records and detailed operational data outside this repository.

## CSV template

`data/field-observations-template.csv` contains only a header. Blank data is intentional. Synthetic network examples are generated by `sampleNetwork()` and always labeled synthetic.
